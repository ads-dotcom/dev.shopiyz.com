STOREFRONT API v1

Temalar için hızlı, güvenli ve tutarlı veri katmanı.

Shopiyz temaları D1'e bağlanmaz. Aynı-origin Storefront Runtime veya mağazaya bağlı headless token; fiyat, varyant, menü, filtre, içerik ve kampanya verisini tek sürümlü sözleşmeden alır.

Mağaza bazlı erişimHer istek doğru mağaza ve yayınlanmış tema bağlamında çözülür.
Güvenli kapsamİstemciler yalnız gerekli storefront:read, storefront:checkout ve müşteri kapsamlarını alır.
Edge performansıKatalog ve içerik yanıtları kararlı cache politikalarıyla sunulur.

// Ana sayfa tema verisini alın
const page = await fetch(

QUICKSTART

Doğru istemci tipini seçerek başlayın

Aynı-origin temalar public uçları kullanır; harici istemciler mağazaya bağlı Storefront tokenı taşır.

Aynı-origin tema

Public GET uçları token taşımadan çağrılır. Müşteri ve checkout işlemleri güvenli oturum çereziyle aynı origin'de kalır.

const page = await fetch(
  "/api/storefront/v1/page?pageType=home&path=/"
).then((response) => response.json());

Headless istemci

Harici istemci için origin allowlist ve işlem bazlı en az yetki kapsamı zorunludur.

curl -H   "X-Shopiyz-Storefront-Access-Token: shpft_…"   "https://store.myshopiyz.com/api/storefront/v1/products"

Koleksiyon filtreleri

Facet değerleri ve ürünler aynı yanıtta gelir; tema yalnız URL sorgusunu yönetir.

const listing = await fetch(
  "/api/storefront/v1/collections/all" +
  "?color=Siyah&size=M&sort=price-asc&page=1"
).then((response) => response.json());

Fiyat ve kampanya

Fiyatlar mağaza para birimiyle biçimlenir; yalnız herkese açık otomatik promosyonlar okunur.

const localization = await fetch(
  "/api/storefront/v1/localization"
).then((response) => response.json());

TEMA GELİŞTİRME KAPSAMI

Harici bir temanın ihtiyaç duyduğu veri yüzeyi

ThemeForest veya özel bir frontend, yönetim veritabanına bağlanmadan aşağıdaki sözleşmelerle çalışır.

Navigasyon

Header, mega menu, mobil menü ve footer için konumlu, çok seviyeli /menus ağacı.

Kategori ve filtre

Koleksiyon, marka, ürün tipi, kategori, etiket, renk, beden, stok ve fiyat facetleri; sayfalama ve sıralama.

Ürün ve fiyat

Varyant seçenekleri, görseller, stok, satış fiyatı, karşılaştırma fiyatı ve mağaza para birimi. Maliyet değeri maskelenir.

Kampanya

Aktif otomatik promosyonlar ve hedef ürün/koleksiyonlar. Özel müşteri kuralları ile indirim kodları hiçbir zaman açılmaz.

İçerik ve SEO

Sayfalar, bloglar, blog yazıları, SEO alanları, tema layout'u ve header/footer shell verisi.

Müşteri ve ticaret

Aynı-origin güvenli oturumla giriş, kayıt, parola, wishlist, yorum, stok bildirimi ve checkout devri.

HEADLESS SECURITY

Checkout, müşteri OAuth, newsletter ve iletişim

Her istemci ayrı origin, redirect URI ve en az yetki kapsamıyla kaydedilir. Eski storefront:read tokenleri checkout veya müşteri yetkisi kazanmaz.

Headless checkout

Fiyat ve stok istemciden alınmaz; sunucu kanonik varyantları doğrular. Her istek benzersiz bir idempotency anahtarı taşır.

curl -X POST   -H "Authorization: Bearer shpft_…"   -H "Idempotency-Key: cart-7f23f2c1"   -H "Content-Type: application/json"   -d '{"lines":[{"variantId":"var_123","quantity":1}],"returnUrl":"https://app.example.com/paid","cancelUrl":"https://app.example.com/cart"}'   https://store.myshopiyz.com/api/storefront/v1/checkout-sessions

React PKCE özeti

Verifier tarayıcıda tutulur; challenge S256 ile üretilir. Callback state ve dönen nonce doğrulanmadan token kullanılmaz.

const verifier = createVerifier();
const challenge = base64url(
  await crypto.subtle.digest("SHA-256", encode(verifier))
);
sessionStorage.setItem("pkce", verifier);
location.assign(authorizeUrl({
  response_type: "code",
  code_challenge_method: "S256",
  code_challenge: challenge,
  state: randomState(), nonce: randomNonce()
}));

Newsletter

Yeni ve mevcut adresler aynı 202 yanıtını alır. Pazarlama izni yalnız e-posta bağlantısı doğrulandıktan sonra etkinleşir.

await fetch("/api/storefront/v1/newsletter-subscriptions", {
  method: "POST",
  headers: {"Content-Type":"application/json"},
  body: JSON.stringify({
    email, locale: "tr-TR",
    source: "footer", consent: true
  })
});

İletişim formu

Aynı-origin tema veya storefront:read istemcisi mesajı mağazanın e-posta kuyruğuna aktarır. Body limiti, honeypot, tenant/IP rate limit ve isteğe bağlı Turnstile uygulanır; yanıt cache'lenmez.

await fetch("/api/storefront/v1/contact-us", {
  method: "POST",
  headers: {"Content-Type":"application/json"},
  body: JSON.stringify({
    name, email, subject, message,
    locale: "de-DE", orderNumber,
    website: ""
  })
}); // 202 accepted

Tehdit modeli

Origin sahteciliği exact allowlist, kod ele geçirme PKCE S256, replay tek kullanımlık kod/token, refresh hırsızlığı rotasyon ve reuse detection, bot trafiği Turnstile/honeypot/rate limit ile sınırlandırılır. Tokenler yalnız hash olarak saklanır.

scope: least privilege
redirect: exact HTTPS URI
access token: 15 minutes
authorization code: 60 seconds
checkout URL: signed + single-use
CORS: explicit origin, never *

Rollout ve geri alma

Yeni yetkiler opt-in'dir. Önce istemciye exact origin/redirect kaydı ve yalnız gerekli scope verilir; pilot doğrulandıktan sonra trafik açılır. Sorunda istemci tokenini revoke etmek erişimi anında keser. Yeni tablolar eklemelidir; eski same-origin checkout, müşteri ve newsletter uçları değişmeden çalışır.

rollout: allowlist → scope → pilot → monitor
rollback: revoke storefront client token
legacy routes: unchanged
database: additive migration
